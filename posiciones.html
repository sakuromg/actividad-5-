Práctica de Posiciones en CSS

Ejemplos

1. Position: static

Es el valor por defecto. Los elementos siguen el flujo normal de la página.

Static

2. Position: relative

Permite mover el elemento respecto a su posición original utilizando propiedades como top y left.

Relative

3. Position: absolute

El elemento se saca del flujo normal y se posiciona respecto a su contenedor padre posicionado.

Absolute

4. Position: fixed

El elemento se posiciona en relación con la ventana del navegador (viewport). (Observa la caja morada abajo a la derecha de tu pantalla).

Fixed

5. Position: sticky

Cambia entre relativo y fijo según el desplazamiento (scroll) dentro del contenedor.

Sticky

Desplaza hacia abajo dentro de este recuadro para ver el efecto adhesivo.
